# سوخان (Sokhan)

دیکته‌ی صوتی روی مک — تبدیل گفتار به متن بر پایه‌ی موتور آنلاین صوتی گوگل، بدون هیچ مدل نصبی.

**سوخان** یک اپلیکیشن مک (مبتنی بر [Handy](https://github.com/cjpais/Handy) با ساختار بازنویسی‌شده) است:

1. کلید میانبر (پیش‌فرض `Alt+Space`) را نگه می‌دارید و صحبت می‌کنید.
2. صدا به **موتور آنلاین صوتی گوگل** فرستاده می‌شود — همان موتوری که Chrome با Web Speech API استفاده می‌کند؛ بدون کلید API، بدون دانلود مدل.
3. متن بلافاصله در برنامه‌ای که جلویش باز است **Paste** می‌شود.

## ویژگی‌ها

- **زیرنویس زنده**: متن_while_صحبت‌کردن روی صفحه نمایش داده می‌شود (استایل Live در تنظیمات Overlay).
- **نیم‌فاصله‌ی فارسی**: می‌شود / کتاب‌ها / سخت‌تر به‌صورت خودکار اصلاح می‌شود (فعال/غیرفعال از تنظیمات Advanced).
- بیلد **Universal**: روی Apple Silicon و Intel مک هر دو کار می‌کند.
- بدون مدل نصبی: هیچ دانلودی لازم نیست، به‌محض نصب آماده است (فقط اینترنت لازم است).
- پشتیبانی از فارسی (`fa-IR` به‌صورت پیش‌فرض) + ده‌ها زبان دیگر با انتخاب در تنظیمات.
- Push-to-talk / Toggle / Hold-or-Toggle با کلید میانبر قابل تنظیم.
- نمایش وضعیت ضبط به‌صورت Overlay روی صفحه.
- حذف خودکار کلمات تکلمی (filler)، اصلاح واژگان سفارشی، تاریخچه‌ی تبدیل‌ها.
- موتور آنلاین: همان پروتکل Sound-Drive-Audio کروم (full-duplex، FLAC روی HTTP/2).

## تفاوت با Handy

- موتور تبدیل گفتار به متن محلی (Whisper/GGUF/ONNX و دانلود مدل) کامل حذف شده و با موتور آنلاین گوگل جایگزین شده است.
- نام، هویت بصری، آیکون و UI جدید؛ ساختار کلی برنامه (میانبر → ضبط → متن → Paste) دست‌نخورده مانده است.
- به‌جای صفحه‌ی دانلود مدل، یک صفحه‌ی ساده «موتور آنلاین» وجود دارد.

## نصب

### macOS
فایل `Sokhan_*_universal.dmg` را از Releases دانلود کنید، Sokhan را به Applications ببرید و اجرا کنید.

پس از اولین اجرا:

- دسترسی **Microphone** و **Accessibility** را در System Settings → Privacy بدهید (برای کلید میانبر و Paste).
- در تنظیمات، زبان گفتار را انتخاب کنید (پیش‌فرض: فارسی).

### Windows
فایل `Sokhan_*_x64-setup.exe` (یا `.msi`) را از Releases دانلود و نصب کنید.

- اپلیکیشن بدون امضای دیجیتال است؛ اگر SmartScreen اخطار داد، **More info → Run anyway** را بزنید.
- کلید میانبر پیش‌فرض: `Ctrl+Space`.
- ویندوز ممکن است اجازه Microphone را بخواهد — Accept کنید.

بیلد ویندوز با GitHub Actions (workflow `windows.yml`) روی تگ‌های نسخه ساخته و به‌صورت خودکار به ریلیز پیوست می‌شود.

> نکته: موتور آنلاین گوگل همان سرویسی است که مرورگر Chrome استفاده می‌کند؛ این سرویس رسمی/مستند نیست و ممکن است تغییر کند.

## توسعه

```bash
npm install
npx tauri dev    # محیط توسعه
npx tauri build  # ساخت .app و .dmg در src-tauri/target/release/bundle
```

- موتور STT (پروتکل + انکودر FLAC استریمینگ): `src-tauri/src/stt/`
- لوله‌ی ضبط/Paste (ساختار اصلی Handy): `src-tauri/src/actions.rs`، `managers/audio.rs`، `clipboard.rs`
